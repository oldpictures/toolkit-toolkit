### the good stuff

- **cover art finder** — find official album and single artwork, with 1000 × 1000 checks.
- **tag editor** — add tags to multiple songs without wiping the ones already there.
- **credits editor** — make editing credits across an album easier.
- **date editor** — fix release dates without the fuss.
- **compare tracklists** — spot missing or mismatched tracks using release metadata.

### getting started

1. [download the extension](docs/downloads/toolkit-toolkit-v0.10.15.zip) and unzip it.
2. in firefox, open `about:debugging` → **this firefox**.
3. click **load temporary add-on** and select `manifest.json` from the extracted folder.
4. head over to [genius](https://genius.com) and start editing.

<sub>heads up: this is a temporary firefox add-on for now. you'll need to load it again after restarting firefox.</sub>

### a note on artwork

artwork suggestions don't change anything on their own. **you choose the cover**, and genius handles the final save. the finder checks for 1000 × 1000 artwork and tries to distinguish standalone singles from album releases.
