01 / features

all the little things.
one place.

built around real genius editing workflows, without a pile of separate tools.

01 / art

artwork lookup

discover album and single covers with official release matching and verified 1000 × 1000 artwork.

02 / organize

tag editor

apply tags to multiple songs while keeping the tags that already exist.

03 / details

credits editor

work across album credits with standardized role handling.

04 / compare

tracklist comparison

find title mismatches against release metadata and review inconsistencies faster.

05 / edit

date editor

cleaner date input for year-only, month-level, and exact-date releases.

06 / control

choose before applying

search artwork without blindly overwriting it; explicit selection and genius's own save remain in your hands.

02 / setup

up and running in
four steps.

01

download

grab the v0.10.15 source archive and extract it to its own folder.

02

open debugging

in firefox, open about:debugging and select “this firefox”.

03

load extension

click “load temporary add-on” and choose manifest.json.

04

edit on genius

reload a genius album or song page to use the toolkit.

heads up: temporary firefox add-ons disappear after a restart. this is not a signed, permanent firefox store installation.
